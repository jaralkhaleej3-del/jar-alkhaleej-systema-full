# نظام جار الخليج المتكامل — مساحة العمل V2.0

**التحديث: 14 أكتوبر 2026**

## ما الجديد؟

- إعادة تصميم شاملة **لواجهة البوابة الرئيسية وشاشة الدخول والإعدادات** بهوية عصرية: بطاقات حديثة، اختصارات واضحة، بحث سريع، رموز SVG مستقلة، دعم الوضع الفاتح والداكن.
- إضافة صفحة مستقلة **دليل مفوتري سداد** باسم `apps/sadad-directory.html`؛ تعرض **93 مفوترًا من قوائم إرشادية منشورة** مع بحث بالاسم أو رقم المفوتر، تصنيف الجهات، وزر نسخ الرمز. لا تنفذ عمليات مالية.
- الإبقاء على **18 تطبيق HTML** من النسخة السابقة دون تغيير في ملفات منطق أعمالها، مع صفحة الدليل الجديدة = **19 تطبيقًا** في القائمة.
- الحفاظ على مسارات التطبيقات وبياناتها ومشاريع Firebase المختلفة، وعلى إعداد PIN أو نمط أو كلمة المرور المعرّف سابقًا على نفس النطاق والمتصفح (`jar-alkhaleej-portal:v1:*`).
- تحسينات مرئية للشاشات الصغيرة (الجوال/الآيباد) على مستوى البوابة، وتظل صفحات البرامج القديمة مستفيدة من طبقة CSS المتجاوبة السابقة، والتي قد تتطلب اختباراً أو تطويراً إضافياً حسب جداولها وشاشاتها الداخلية.

## ترتيب الحزمة

```text
index.html                 ← بوابة النظام الرئيسية
apps/                     ← التطبيقات الأصلية + sadad-directory.html
assets/                   ← ستايلات البوابة وبرمجتها + icons.svg
catalog.json              ← فهرس التطبيقات وروابطها
manifest.webmanifest      ← إعدادات تطبيق الويب
.nojekyll                 ← لدعم GitHub Pages
DEPLOY_GITHUB_PAGES_AR.md  ← كيفية تحديث مستودع GitHub
CHANGELOG_V2_AR.md        ← تفاصيل التحديث
```

## تحديث مستودع GitHub الحالي

- المستودع: `jaralkhaleej3-del/jar-alkhaleej-systema`.
- **الأبسط والأضمن:** استخرج الملف `Jar_Al_Khaleej_Modern_v2_Full.zip` وارفع محتوياته مباشرة إلى جذر مستودع GitHub (لا ترفع ZIP بحد ذاته). استخدم GitHub Desktop للاحتفاظ بمجلدَي `apps` و`assets` ودمج الملفات المتكررة بشكل صحيح.
- أو استخرج `Jar_Al_Khaleej_Modern_v2_Update_GitHub.zip` وانسخ الملفات الموجودة فيه إلى المجلد المحلي المرتبط بمستودع GitHub، مع **الاستبدال عندما يطلب النظام ذلك**، ثم Commit وPush.
- تحقق من وجود `index.html` على مستوى الجذر و`assets/portal.css` و`assets/portal.js` و`assets/icons.svg` و`apps/sadad-directory.html`.
- افتح رابط Pages بعد النشر، وإذا بقيت الواجهة القديمة جرب `Ctrl + Shift + R`.

## دليل سداد وملف الاختصار

ملف `دليل مفوتر سداد SADAD.lnk` الذي أرسلته هو اختصار Chromium/Chrome يحتوي مُعرّف تطبيق مثبت محليًا، **ولا يكشف العنوان الأصلي للموقع بطريقة يمكن التحقق منها**. لذلك لم يُحوَّل الاختصار نفسه إلى موقع.

بدلاً من ذلك أضيفت صفحة بحث محلية تحتوي قائمة إرشادية مقتبسة من جهات منشورة (المصدر الإرشادي: https://tool-sa.com/tools/sadad-directory)، كما أُدرج رابط إلى موقع ويب يحمل العنوان نفسه الذي أرسلته: https://ed3s.com/sdad/، وإلى صفحات البنك المركزي السعودي ووزارة المالية.

**تحقق من رمز المفوتر واسم الجهة داخل تطبيق البنك أو الجهة الرسمية قبل إتمام أي عملية سداد.** هذه القائمة ليست متصلة لحظيًا بنظام سداد.

## الأمان (ضروري قبل الاستخدام الحقيقي)

- قفل PIN/النمط/كلمة المرور الحالي **واجهة محلية** فقط، وليس مصادقة فعلية، ولا يمنع أي شخص من فتح الملفات المنشورة تحت `apps/` مباشرة.
- يجب استخدام Firebase Authentication وقواعد Firestore الصارمة أو استضافة خلف حاجز دخول حقيقي؛ **لا يكفي جعل مستودع GitHub خاصًا لحماية GitHub Pages المنشور**.
- ما زالت بعض التطبيقات تطلب تسجيل دخول مستقلًا. لم يتم تعديل قواعد Firebase أو بيانات الطلبات أو الأصول أو الصناديق أثناء إعداد التحديث.
- تجنّب نشر كلمات مرور أو مفاتيح خاصة أو بيانات اعتماد تشغيلية في ملفات HTML/JavaScript العامة.
- يتطلب قفل WebCrypto التشغيل عبر `https://` (مثل GitHub Pages) أو `http://localhost` ولا يعمل عند الفتح المباشر بطريقة `file://`.

## الاختبار

- اختبار الواجهة في متصفح Chromium بمحاكاة فقط؛ أظهرت القائمة 19 تطبيقًا.
- اختبار العثور على دليل سداد وفتح مسار صفحته من البوابة، وتبديل المظهر، وقفل الواجهة وإعادة الدخول، وتغيير PIN إلى نقش نمط.
- اختبار صفحة سداد: عرض 93 مفوترًا، البحث عن `050` وعرض وزارة الموارد البشرية، والفلترة حسب التصنيف.
- اختبار شاشة الجوال بعرض 390px دون تمرير أفقي في **البوابة الرئيسية**.
- **لم يتم اختبار Firebase الحقيقي ولا عمليات حفظ جميع التطبيقات على GitHub Pages**. نوصي باختبار قبول وتشغيل على المستودع المنشور بعد الرفع.
